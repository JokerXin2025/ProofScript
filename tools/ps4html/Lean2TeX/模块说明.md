# Lean2TeX 模块说明

Lean2TeX 接收 ProofScript 导出的 ExprJSON，根据证明模块导入的 Lean 配置生成 DisplayTree 和 TeX。配置声明在 Lean 文件中；渲染器不读取 TOML。

## 配置链路

1. `ProofScript/Info/Command.lean` 定义六个统一 Info 命令。领域结构体派生 schema，共用事务、来源跟踪和导入解析；基础表达式展示位于 `Defaults/Lean2TeX.lean`。
2. Lean 在 `page_end` 或独立产物的模块结束边界完成配置合并、冲突检查和 alias 闭包校验，保存已规范化的冻结快照。模块自身的配置在该模块消费时生效。
3. `proofscriptExport` 从 `.olean` 导出 `.ProofScript/info/snapshots/` 和生成 schema；`info/index.json` 是包含摘要、版本和产物关联的完成清单。模块事件仅供诊断，Python 不重放事件。
4. `PS4HTML/info.py` 校验完成清单、快照、模型 schema 和调用契约；`configuration.py` 只将冻结值适配为渲染模型，不再维护字段白名单、默认值或合并算法。
5. `Expr2TeX.from_config(config)` 为每个证明/语言面板创建独立的变量分配器和诊断状态。缓存重渲染只消费 `.PS4HTML/inputs/` 中的完成版本，无需执行 Lean。

`def_info` 目标和 alias 目标必须是已经声明的 Lean 常量。`alias`、`unwrap` 是优先解释的模式；只有 `calc_symbol` 而无 styles 时，Lean 在冻结时为二元关系生成优先级 50、无结合方向的中缀样式。`styles` 以整个有序数组覆盖，`phrase_info.template` 按语言更新，`var_info.names` 保存池顺序。省略字段沿用已有配置，`none` 显式清除，`reset` 恢复 schema 默认值。

## Python 文件职责

| 文件 | 职责 |
| --- | --- |
| `configuration.py` | 读取完成快照，将规范值适配为 MacroRegistry 和变量配置 |
| `macros.py` | `MacroRegistry`、模板选择器与宏布局验证 |
| `semantic.py` | ExprJSON 转换为 DisplayTree，解析应用参数、fvar、binder 与 bvar |
| `renderer.py` | 布局、优先级/括号、文本与公式模式、TeX/KaTeX 语义引用 |
| `variable.py` | `var_info` 命名池、变量名称分配及 fvar 缓存 |
| `core.py` | `Expr2TeX` 公共接口及按导出目录/模块加载 |

`#N` 指筛选后的语义子节点，`@N` / `@@N` 在 `binders := [(N, count)]` 指定的 lambda 中选择 binder 和后续部分。某个 style 依赖 binder 时，需保留不使用 `@` 的后备样式；同名 style 依声明顺序选择。`unwrap` 则按包括隐式参数在内的原始应用参数下标选取。

变量高亮身份不依据显示名称：fvar 使用 `fvarId`，binder/bvar 使用同一次转换的 `bindId` / `bindRef`。`renderer.py` 输出 `\htmlData`，浏览器只在最近的 `.theorem-proof` 中联动同组引用。
